# Swipeable row actions

The mobile swipe-to-reveal pattern, implemented on the web using native scrolling and CSS scroll snap.

Swipe a row with touch or a trackpad to reveal its actions. The browser handles gestures, momentum, and snapping between open and closed positions. JavaScript adds visual feedback as the actions appear, with no gesture library.

Three variations: circular, circular with leading actions, and classic.

```sh
npm install
npm run dev
```

`npm run build` checks TypeScript and builds the demo.
